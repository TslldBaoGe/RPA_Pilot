# RPA机器人 · 项目全景说明

> 本文档覆盖整个系统的两部分：**桌面客户端「RPA机器人」**（本仓库，Electron 应用）与
> **网页端「RPA管理后台」**（`D:\SwagTslldLocalAIProject\RPA机器人控制台`，React + FastAPI）。
> 当前版本：客户端 **0.1.24**。

---

## 一、系统总览

```
┌──────────────────────┐         HTTPS (每5秒)          ┌──────────────────────────┐
│  RPA机器人 客户端      │ ──心跳/任务同步/运行记录上报──▶ │  RPA管理后台（网页）        │
│  Windows 桌面应用     │ ◀──拉取指令（执行/停止/改计划…）─│  http://8.134.166.149/    │
│  Electron + Vue3     │                                │  React + FastAPI + SQLite │
│  本机 Python 任务执行  │                                │  部署在腾讯云服务器         │
└──────────────────────┘                                └──────────────────────────┘
```

- **客户端主动外连**：机器人机器人在内网也无需公网 IP / 端口映射，出站连接即穿透 NAT。
- **一台管理后台管多台机器人**：每台客户端有唯一 `machineId`（首次启动生成，存本地数据库），
  管理后台按 `machine_id` 区分机器人，任务/计划/指令都定向到指定机器人。
- **指令模型**：管理后台把指令写进 `commands` 队列表，客户端每次心跳取走并执行，
  执行结果回传（成功 / 失败原因 / 附带数据）。指令最坏延迟 ≈ 5 秒。

## 二、桌面客户端 RPA机器人（本仓库）

### 2.1 技术栈

| 层 | 技术 |
|---|---|
| 框架 | Electron 44 + electron-vite |
| 界面 | Vue 3 + Element Plus |
| 本地存储 | better-sqlite3（WAL 模式） |
| 打包/更新 | electron-builder（NSIS 向导）+ electron-updater（差量下载） |
| 任务执行 | 本机 Python（Miniconda 环境或自定义解释器） |

### 2.2 功能清单

**任务管理（TasksView）**
- 新建/编辑/删除任务：绑定 `.py` 脚本（工作目录 `tasks\` 内相对路径、绝对路径、UNC 网络路径均可）、
  指定 Python 环境（自动探测 Miniconda，或绑定自定义解释器路径）、超时、并发策略（跳过/排队）、
  失败重试次数、失败通知。
- 执行 / 终止；日志抽屉实时输出，每行左侧带 `HH:mm:ss.SSS` 实时时间戳。
- 每次执行的日志独立成文件（`logs\<任务id>\<时间>_<runid>.log`），多次执行互不覆盖。

**定时调度（core/scheduler.ts）**
- cron 表达式定时触发；客户端重启后按数据库状态重建全部计划；
  对"客户端关机期间错过的触发"按上次应触发时间做补偿判断。

**右下角悬浮运行状态框（floating-status.ts + FloatingStatusView）**
- 运行开始即出现：绿色左边条 + 机器人图标 + 任务名 + 状态/时长。
- **同一流程（任务）只显示一张卡**：同一任务再次运行时新卡顶掉旧卡，不堆叠。
- 运行结束后卡片保留，显示成功/失败结果，直到手动关闭。
- 点 ✕：运行中 → 停止该次运行；已结束 → 关闭卡片。**关闭后自动唤起客户端主界面**。
- 点卡片本体：唤起主窗口。
- screen-saver 级别置顶（RPA 驱动全屏应用时状态框始终可见）。

**运行记录（RunsView）**
- 全部执行历史：状态（运行中/成功/失败/超时/已终止）、耗时、错误摘要。
- 触发方式中文显示：**机器人手工**（本机点的）/ **管理后台手工**（网页下发）/ **定时**。

**Python 环境管理（core/conda.ts、python-probe.ts、EnvironmentView）**
- 自动探测本机 Miniconda；未找到可手动指定目录。
- 每个任务可绑定 conda 环境，或直接绑定一个解释器 exe。
- 环境列表创建 / 状态查询。

**Git 集成（core/git.ts）**
- 可选：从 git 仓库拉取最新脚本更新任务（Settings 页操作）。

**失败通知（core/notify.ts）**
- 任务失败后可选推送飞书群机器人 webhook（任务级开关）。

**云端代理（core → cloud-agent.ts，本项目的核心链路）**
- 每 **5 秒**：POST `/agent/heartbeat`（machine_id、主机名、Windows 登录用户名、版本、是否运行中），
  同时取回待执行指令 —— 管理后台下发指令的最坏延迟 ≈ 5 秒。
- 每 **10 秒**：全量同步任务清单（含"此刻是否运行中"）与最近 100 条运行记录到管理后台。
- 支持的指令（`executeCommand`）：

| 指令 | 作用 |
|---|---|
| `run_task` | 执行指定任务（触发方式记为「管理后台手工」） |
| `stop_run` | 终止指定运行 |
| `update_task` | 改 cron / 启用停用 |
| `deploy_scripts` | 下载管理后台上传的脚本包，解到 `packages\<包名>\`（同 hash 幂等跳过） |
| `create_task` | 用已部署的包创建任务（路径自动定位到 packages 目录；兼容旧双重编码 payload） |
| `get_run_log` | 读取某次运行的日志文件回传（超 256KB 自动取尾部） |

- 服务器地址默认 `http://8.134.166.149`，可用设置键 `cloudServer` 覆盖；环境变量
  `RPA_PILOT_CLOUD=0` 可整体关闭。

**应用更新（updater.ts + electron-builder.yml + resources/installer.nsh）**
- 差量下载（blockmap）：实测 118MB 更新只下载 1.3MB。
- 下载失败自动退回整包重试。
- 安装走 **NSIS 向导**（降低杀软 DLL 误报），**装完/更新完自动启动客户端**（customInstall 宏兜底，
  不依赖向导的"完成后运行"复选框）。
- 有任务运行时阻止安装更新。
- 更新源默认国内服务器 `http://8.134.166.149:8088/`，运行时可被设置覆盖。

**其他**
- 托盘常驻、开机自启（autorun 钩子 `RPA_PILOT_AUTORUN=1`）、单实例锁。
- AUMID 身份守卫（core/aumid-guard.ts）：清理开始菜单里劫持了 `com.rpapilot.desktop`
  身份的冒牌快捷方式，修复任务栏图标显示成 Electron 的问题。

## 三、管理后台（RPA管理后台）

> 仓库：`D:\SwagTslldLocalAIProject\RPA机器人控制台`；线上 http://8.134.166.149/

### 3.1 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python FastAPI + SQLite（单文件 `backend/main.py`，约 1500 行） |
| 前端 | React 18 + Ant Design 5 + Vite |
| 服务 | systemd `rpa-console.service`（127.0.0.1:8100）+ nginx 80 反代（静态资源 + `/api`、`/agent`） |

### 3.2 功能清单

**登录与会话**
- 登录页独立路由；PBKDF2-SHA256 密码散列；会话令牌 7 天有效。
- **全接口鉴权**：除登录外所有 `/api` 都要 Bearer 令牌；未登录访问任何页面强制跳登录页，
  会话过期自动弹回登录页，已登录访问 /login 自动回主界面。

**角色与权限（可自定义角色）**
- 6 个权限点：查看 / 执行任务 / 任务与计划增删改 / 应用上传删除 / 机器人备注删除 / 账号与角色管理。
- 内置三角色（不可改删）：管理员（全部）、操作员（查看+执行+任务+应用）、访客（只读）。
- **自定义角色**：角色管理页自由勾选权限点创建，改动实时生效（该角色用户的下一次请求即按新权限判定）。
- 所有页面按钮与后端接口双重按权限判定（前端 `hasPerm()` 隐藏 + 后端 `require_perm()` 拦截）。

**账号管理**
- 登录账号、姓名、角色、账号状态（停用立即踢掉该用户全部会话）、最近登录时间、创建时间。
- 新建/编辑（重置密码、改角色）、删除；内置 admin 不可删不可降级。

**工作台（Dashboard）**
- 大字显示**在线机器人**数量，小字"共 X 台机器人"；今日运行、今日成功率、本周异常。
- 近 7 日运行趋势、最近 8 条运行记录（触发方式中文）。

**机器人管理**
- **在线列**（在线/忙碌/离线）、主机用户名（客户端心跳上报）、备注（管理员可编辑）、
  最近 2 次运行的任务名、版本、累计运行次数、最近心跳。10 秒自动刷新。

**任务管理**
- 实时任务清单（机器人回传同步）：任务名（运行中带蓝色「执行中」标签）、执行机器人、
  cron、启用开关（下发生效）、最近运行。10 秒自动刷新。
- **执行 / 终止**：下发指令到指定机器人（最坏 5 秒响应）。
- **远程建任务**：选机器人 + 选脚本包 + cron → 下发 `deploy_scripts` + `create_task` 两条指令，
  机器人自动下载部署并建任务，10 秒内回同步。

**计划任务**
- 按 cron 定时下发/启停（与任务管理同一套指令链路）。

**应用管理**
- 上传 Python 脚本包（多文件、指定入口 .py），存 SQLite（base64），显示 hash 指纹/文件数/大小；
  上传后可在「任务管理 → 远程建任务」或「计划任务」下发到机器人自动部署。

**运行记录**
- 全部机器人执行历史：状态筛选、自动刷新、触发方式（机器人手工/管理后台手工/定时）。
- **远程查看日志**：每行「日志」按钮 → 向机器人下发 `get_run_log` 指令 → 抽屉展示完整日志
  （机器人离线/超时/版本过旧都有明确提示）。

### 3.4 后端接口一览

| 分组 | 接口 | 权限 |
|---|---|---|
| 会话 | POST `/api/login`、GET `/api/me`、POST `/api/logout` | 公开 / 登录 |
| 数据 | GET `/api/summary` `/api/robots` `/api/tasks` `/api/runs` `/api/schedules` `/api/scripts` `/api/roles` `/api/users` `/api/commands/{id}` | 登录 |
| 任务 | PUT `/api/tasks/{machineId@taskId}`、POST `/api/tasks/remote` | manage_tasks |
| 执行 | POST `/api/tasks/{ref}/run`、`/api/runs/{ref}/stop` | run |
| 日志 | POST `/api/runs/{ref}/log`（下发指令）、GET `/api/commands/{id}`（轮询结果） | 登录 |
| 计划 | POST `/api/schedules/{ref}/toggle` | manage_tasks |
| 应用 | POST `/api/scripts`、DELETE `/api/scripts/{id}` | manage_apps |
| 机器人 | PUT `/api/robots/{machine_id}/remark` | manage_robots |
| 账号 | POST/PUT/DELETE `/api/users` | manage_users |
| 角色 | POST/PUT/DELETE `/api/roles`（内置角色只读；删角色须无人使用） | manage_users |

Agent 协议（`/agent/*`，请求头 `X-Agent-Token: rpa-cloud-2026`）：
`POST /agent/heartbeat`（心跳+取指令）、`POST /agent/sync`（任务清单）、
`POST /agent/runs`（运行记录）、`POST /agent/command-result`（指令结果，支持携带日志数据）、
`GET /agent/scripts/{id}/download`（脚本包下载）。
